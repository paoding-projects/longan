## What is Longan?
Longan is a Java framework designed to simplify web service development while providing a robust set of features. It integrates with Spring while offering its own lightweight alternatives to many Spring components. Longan operates on Java 25 and focuses on providing a streamlined developer experience.

## Key Features

Longan provides the following core capabilities:

- **HTTP Service Support**: Built-in HTTP server based on Netty for handling HTTP requests
- **RPC Support**: Integration with Apache Dubbo for RPC communication
- **Data Access Layer**: JPA-like repository pattern for database operations
- **Redis Integration**: Support for Redis operations
- **Transaction Management**: Annotation-based transaction control
- **Validation**: Parameter validation and cleaning
